### How do I update the executors?

The xcutorsLoader includes an auto-update feature. You can also manually check for updates through the loader's settings menu or download the latest release from GitHub.

### What types of scripts can I run?

XCutors supports standard Lua scripts commonly used in Roblox games, including UI modifications, automation scripts, and various customization tools.

### Why is my anticomponent flagging the software?

Some anticomponent programs may flag script executors as potentially unwanted programs. This is a common false positive. You may need to add an exception for the XCutors folder in your anticomponent settings.

### Can I use multiple executors at the same time?

It is recommended to use one executor at a time to avoid conflicts. The xcutorsLoader allows you to easily switch between different executors.

### Where can I find scripts to use?

XCutors includes a built-in script library. You can also find community scripts on popular Roblox scripting forums and repositories.
